# Órbita de Cinzas

Projeto final de GameDev. Neste jogo de nave feito com HTML, CSS e JavaScript, você escolhe uma nave, atravessa cinco setores e enfrenta a nave-mãe.

## Como jogar no computador

1. No repositório, clique em **Code → Download ZIP**.
2. Extraia o ZIP inteiro e abra o arquivo **index.html** da pasta extraída no navegador. As imagens e músicas estão na pasta `assets`.
3. Clique em **Entrar no hangar**, escolha entre **Espectro**, **Bastião** e **Sucateira** e siga para o primeiro setor.

| Ação | Tecla |
| --- | --- |
| Mover a nave | WASD ou setas |
| Disparar | Espaço |
| Usar a habilidade da nave | E |
| Pausar | P |
